# PS4 Games Database — Android APK

The web app is being prepared for Capacitor.

## Architecture

- The existing HTML/CSS/JS remains the main UI.
- Capacitor wraps the same interface in an Android application.
- The PS4 metadata backend remains on Vercel.
- When running inside the APK, metadata requests use the Vercel API instead of a local ./api path.
- The Android project is generated by GitHub Actions, so the repository does not need to commit the generated android/ directory.

## Build

Use GitHub Actions → **Build Android APK**.

The workflow:
1. installs Node and Java;
2. installs Capacitor;
3. generates the Android project;
4. syncs the existing web app;
5. builds a debug APK;
6. uploads the APK as a workflow artifact.

The APK is not yet signed for Google Play. This first stage is for direct Android installation/testing.
