Créditos

Criação e desenvolvimento

Miguellbr — criador e desenvolvedor desta versão do PS4 Games Database.

Biblioteca base

Esta versão é um fork de huggingfacer04/ps4-games-database, que fornece a biblioteca/catalogação original utilizada como base do projeto.

Instalador de PKG

A integração do motor de instalação foi desenvolvida a partir das APIs e do trabalho do DirectPackageInstaller, criado por marcussacana. O DPI original é um projeto separado; esta aplicação implementa seu próprio fluxo integrado.

Os créditos não significam que os projetos externos sejam mantidos ou endossados por este app.
